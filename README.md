# RAG Ontologia Project

This project contains the development and implementation of solutions for the RAG (Retrieval-Augmented Generation) Ontology challenges, developed at the **Hospital Clínic de Barcelona**, Department of Clinical Informatics.

## Project Structure

The project is organized into two main distinct directories, each addressing a specific problem statement:

### `ofarres/`
This directory contains the solution to the **First Problem Proposal**.
It includes the initial implementation and approaches developed to solve the original challenge set forth in the project scope.

### `new_ofarres/`
This directory contains the solution to the **New Problem Proposal**.
It houses the updated methodologies, new algorithms, and distinct strategies applied to tackle the subsequent or revised problem statement.
